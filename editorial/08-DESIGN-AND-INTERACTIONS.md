# Creative direction | CHILI translated into a website

**Design source:** `reference/CHILI-9-0-LS-Oct-22.html`. It is a presentation about PET physiography, not a template for the lab's scientific scope. Borrow its editorial precision, quiet dark palette, tight typographic control, restrained animations, labelled charts, meaningful progressive reveals and direct attribution.

**Palette from source:** warm black `#0b0a09`; warm white `#f1eeea`; secondary `#c4beb7`; muted `#a59e96`; divider `#2a2622`; restrained scientific accents coral `#e36b63`, pale blue `#a9bbc9`. Scientific colour semantics always override decorative brand usage.

**Type:** A single clean contemporary sans-serif, clear numeral rendering, large but readable headlines, carefully limited line lengths. The source uses embedded Inter binaries; do not copy/share embedded font files. Choose a legally available font through standard install/hosting.

**Layout:** Standard navigation, non-slide continuous scroll. Hero almost entirely typographic. Each content region has a clear idea and space to breathe. Do not enforce 100vh sections or put every research example in an equal card.

**Motion:** Only to show comparison, change across time, source linking or drill-down. Never fake scientific signal motion or change numerical data through animation. Allow pause, keyboard controls and reduced-motion alternative. Client-side precomputed assets only, no paid GPU calls.

**Hero:** No total-body PET hero background or single modality image that implies exclusivity. If scientific imagery is used, juxtapose authentic artefacts across different relevant work, or omit imagery entirely.

**Computability module:** Two short examples (image-derived quantitative measurement, source-linked text observation). The image is already numerical. Use real cleared assets when possible; synthetic text must be labelled. Keep explanation to a glance, with expandable provenance.

**Research examples:** Curate real figures, not decorative cards. On each: the question, the actual figure, what it shows, the link, and what remains unclear where relevant. Physiological work should be visible but not the only scientific exemplar. No speculative agent demo masquerading as an executed research system.

**Tools grid:** Responsive asymmetric bento grid. Card size responds to genuine image/interface content. Public/private availability explicit. Code/documentation reachable in one interaction. Site does not host inference.

**People:** Real portraits, names and first-person researcher answers. The warmth comes from the material, not hover gimmicks or fabricated handwritten captions. All content reachable without hover on touch devices.

**Navigation:** Home (logo), Research, Tools, Projects, Publications, People, Contact. Footer includes affiliation, contact, legal/privacy notices as required by hosting institution.

**Launch acceptance:** Verify contrast, keyboard navigation, image permissions, accessible figures/alt text, mobile clipping, typography, meaningful loading states, no false metrics, no invented content, no phantom links, no unpublished competitive work.
