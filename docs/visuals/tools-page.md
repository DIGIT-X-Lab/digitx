# Tools catalogue and detail pages

26 October 2026. Mode: Read, with direct access to software.

The PI approved the catalogue direction and clarified its premise: tools arise from problems encountered in the lab's own research into biology, then are shared as open-source software where possible. The current introduction in `src/content/tools.ts` and `editorial/03-TOOLS.md` expresses that history without presenting the lab as a software vendor.

## Composition

Continue the Home and Research visual system: warm black, ivory title strip, shared Inter type roles and the same wide shell. Put the lead below the heading, spanning the available width. Never reduce its type size to fit. Catalogue controls follow at a 48px interval on desktop, 32px on mobile.

On 29 October 2026, the PI chose the full-width list with a focused demonstration from the three-way Tools comparison. This replaces the former split preview and inline expansions. The comparison source is archived in `design-previews/tools-layout-review-2026-10-29.zip`; its runtime switcher, test records and environment gate have been removed.

Each row contains a tool name, a verified GitHub star count, one approved plain-English description and a single diagonal arrow. The always-visible logo sits in a fixed column to the left of the name; the star count follows the name closely, without a hidden logo between them. Image/Text labels remain in the filters and focused-view metadata, not on every row. Star counts come from the dated GitHub API snapshot in `src/content/tool-stars.json`, refreshed with `node scripts/fetch-tool-stars.mjs`; the repository URL must match before its count is displayed. The title/accessibility label includes the check date, and the focused GitHub link repeats the count. The list stays in place when a row is selected. Clicking or using Enter/Space opens a native modal with the existing `ToolStudy` animation, its approved explanation and Explore tool, verified Paper and GitHub actions. Close, Escape or clicking the backdrop returns to the originating row, preserving scroll position. The explicit trigger reference also restores focus after a Safari pointer click. The same interaction works on mobile; rows reflow into two lines below 1000px.

Hover or keyboard focus shows a flowing ivory surface, black text and the black tool icon. The surface sits in an explicit stacking context behind the row and uses normal blending. The ivory surface provides keyboard focus indication; omit the extra rectangular focus outline at the PI’s request. The prototype accidentally painted its difference-blend surface above already-black text, making both the text and logo disappear. This correction is scoped to the released tool list; Research and forthcoming-tool highlights retain their own behaviour. Touch has no sticky hover; reduced motion makes the surface immediate.

Search and All/Image/Text filters apply to the entire collection before pagination. Eight released tools appear per page; pagination is omitted for a single page. When needed, use one centred line with previous/next arrows, first/current/last page numbers, compact gaps, and an underlined current page. The range is quieter text on desktop and screen-reader-only on narrow screens. Image tools precede Text tools. The existing three forthcoming tools remain a separate section with their original demonstrations. Empty search results offer a reset. Counts are announced through a screen-reader status region. No repeated test records ship in the catalogue.

Only the open released tool study is mounted. The focused view opts into looping playback, including MOOSE’s contour reveal and LION’s fixed-mask reveal. Hover and document-field selection do not stop the loop; explicit pause, visibility and reduced-motion preferences still apply. A 160ms dialog entrance provides a distinct transition from Research's expanding rows; reduced motion omits this entrance. The PI requested removal of the released-software hosting sentence. Individual detail pages continue to contain installation, requirements and licence information.
